Invariant 1: Unconditional Safety

Under asynchronous network delay with $n \ge 3f + 1$, no two conflicting transactions can obtain Quorum Certificates at the same slot. Fast path requires $3f+1$, intersecting any slow quorum $2f+1$ in at least $f+1$ honest nodes.

Invariant 2: Liveness after GST

Under partial synchrony, once Global Stabilization Time (GST) is reached, non-conflicting proposals finalize in 1 RTT, and conflicting proposals finalize via 2-phase slow path in 2 RTTs under Pacemaker view change bounds.

Invariant 3: Speculative Non-Linearizability

Speculative results returned during the 1-RTT flight window are explicitly tagged TENTATIVE and isolated in ephemeral MVCC branches. Read API strictly distinguishes tentative uncommitted reads from linearizable finalized reads.

Invariant 4: Qualified O(1) Logical Rollback

Branch invalidation redirects root pointers in $O(1)$ operations without cluster-wide stalls. Physical node memory pruning and garbage collection occur asynchronously off the consensus critical path.
